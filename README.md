# TaskFlow - Modern To-Do List Web Application

A clean, responsive, and intuitive To-Do List web application built with vanilla HTML5, CSS3, and JavaScript.

## ✨ Features

- ➕ **Task Management**: Create tasks quickly with real-time validation and keyboard support (<kbd>Enter</kbd>).
- ✅ **Completion Toggle**: Mark tasks complete with custom styled checkboxes and animated strike-throughs.
- 🗑️ **Task Deletion**: Remove tasks with smooth slide-out removal transitions.
- 🔍 **Filtering**: Switch between **All**, **Active**, and **Completed** tasks instantly.
- 💾 **Persistence**: Automatic synchronization with `localStorage` so tasks remain saved across page refreshes.
- 🧹 **Batch Cleanup**: One-click "Clear Completed" button.
- 📱 **Modern & Responsive Design**: Glassmorphism UI, gradient backdrop, smooth micro-interactions, and mobile responsiveness.

## 🚀 Getting Started

### Option 1: Direct in Browser
Simply clone the repository and open `index.html` in your favorite web browser:
```bash
git clone https://github.com/Ganeshgoudbandi0810/to-do-app.git
cd to-do-app
```
Double-click `index.html` or open with:
- Windows: `start index.html`
- macOS: `open index.html`
- Linux: `xdg-open index.html`

### Option 2: Run with Node.js Server
```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.
